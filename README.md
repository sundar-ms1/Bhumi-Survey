# Bhumi Survey - Topo Mapping & Surveying Consultant
## Production-Ready Website Package

This ZIP package contains the complete, modern, mobile-responsive business website for **Bhumi Survey - Topo Mapping & Surveying Consultant**.

### Files Included:
1. `index.html` - The full corporate landing page, featuring:
   - High-conversion presentation of surveying and contouring services
   - Verified project track record (Amble School Chikkamagaluru & Banashankari layout)
   - **"Request an On-Site Survey Visit"** booking module with:
     - Subtitle: *"Complete the project brief below to receive a call back and mobilization date"*
     - Direct WhatsApp routing to `+91 74830 91924` or `+91 83106 89058`
     - Live interactive WhatsApp preview window
2. `logo.svg` - The custom high-resolution vector emblem matching your official brand logo (emerald green letter 'B', integrated Total Station, topographic elevation contours, orange swoop arc, and compass star with north indicator).

### How to Use / Host:
- **Test Locally**: Simply double-click `index.html` to open it in Chrome, Edge, Safari, or Firefox.
- **Publish Online**:
  - **Netlify / Vercel**: Drag and drop this unzipped folder into Netlify Drop (app.netlify.com/drop) or Vercel to get a live URL in 30 seconds.
  - **cPanel / Web Hosting**: Upload `index.html` and `logo.svg` to your `public_html` directory.
  - **GitHub Pages**: Push this repository to GitHub and enable Pages in repository settings.
